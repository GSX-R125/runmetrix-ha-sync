# 手動同期ボタン

`local_buttons.yaml` はRDM取得とDrive転送の2ボタン、`drive_sync_now_local.yaml` はDriveだけのボタンです。Home Assistantのダッシュボードでカードを追加し、手動カードのコードエディターへ内容を貼り付けます。管理者アカウントでボタンを押すと対象アプリを再起動し、起動直後の同期を実行します。定期実行の間隔は再起動時から数え直します。

これらのYAMLは**ローカルアプリ**のID `local_runmetrix_sync` / `local_runmetrix_drive_sync` を指定しています。GitHubリポジトリからアプリを導入した場合は、各アプリの情報画面で実際のIDを確認し、YAML中の `app:` の値を置き換えてください。RDM取得完了後にDrive転送を押すと新規分をすぐ送れます。

`clean_run` がONのアプリをボタンで再起動すると、クリーン処理がもう一度実行されます。普段はOFFにしてください。両アプリを同時に起動した場合は共有ロックで直列に実行しますが、順番を指定するものではありません。
